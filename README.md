# API TypeScript

## Requisitos

- Node.js
- npm

## Instalación

```bash
npm install
```

## Ejecutar

```bash
npm run dev
```

## Compilar

```bash
npm run build
```

## Ejecutar producción

```bash
npm start
```

Servidor:

http://localhost:3000

## Endpoints

GET /users

GET /users/:id

POST /users

PUT /users/:id

PATCH /users/:id

DELETE /users/:id
